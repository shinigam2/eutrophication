# Интеллектуальная система мониторинга и прогнозирования эвтрофикации водоёмов Беларуси

Командный курсовой проект (4 участника). Система объединяет **реальные спутниковые снимки Sentinel-2 L2A**, **суточную погоду NASA POWER**, **лабораторные анализы воды (БГУ / НСМОС)**, **машинное обучение**, **семантическую базу знаний (W3C SOSA/SSN)** и **интерактивную веб-ГИС** для прогноза эвтрофикации и риска цветения водоёмов на горизонт **10 дней**.

Система поддерживает **два режима работы**:
- **Спутниковый режим** — работает автоматически для любых крупных озёр Беларуси (включая живое добавление нового озера по одной команде).
- **Лабораторный режим** — использует реальные лабораторные пробы хлорофилла-а (для озёр Нарочь, Мястро, Баторино и др.) для отдельного прогнозирования и локальной калибровки спутниковых оценок.

## Границы применимости (чего система НЕ делает)
Система является исследовательской **СППР для аналитика** по открытым данным: она **не** работает в режиме реального времени 24/7, **не** видит воду сквозь сплошные облака и зимний лёд, **не** подходит для сверхмалых водоёмов `< 0,15 км²`, **не** измеряет со спутника токсичность (цианотоксины), pH, кислород и аварийные сбросы и **не** заменяет аккредитованный лабораторный контроль СанПиН (полный перечень из 8 ограничений — в [`DECISIONS.md`](DECISIONS.md), Решение 10).

## Быстрый старт (Часть 1 + общая инфраструктура Docker)
```bash
# 1. Поднять общую инфраструктуру команды: PostGIS (:5432) + Oxigraph (:7878)
docker compose up -d

# 2. Загрузить контуры озёр (GeoJSON -> MultiPolygon) и все витрины Части 1 в PostGIS
#    (либо локально через .venv, либо переносимо внутри контейнера --profile etl)
.venv/bin/python3 -m src.etl.load_to_postgis
# или без установки Python/GDAL на хост:
docker compose --profile etl run --rm etl

# 3. Загрузить базовый граф Части 3 (volkovich) и свежие прогнозы Части 2 в живой Oxigraph
.venv/bin/python3 src/knowledge_graph/graph_cli.py import-ttl --endpoint http://127.0.0.1:7878
.venv/bin/python3 src/knowledge_graph/graph_cli.py import-results --endpoint http://127.0.0.1:7878

# 4. Пересобрать витрины из локальных кэшей (без повторного скачивания, ~4 с)
.venv/bin/python3 -m src.etl.run_pipeline --skip-fetch --skip-gloria-lab --to-postgis

# 5. Прогнать все автотесты (радиометрия, OSM, БГУ, GLORIA, утечки будущего, PostGIS, Oxigraph)
.venv/bin/pytest -v

# 6. Демонстрация на защите: переключите enabled: true у rossokhi в configs/water_bodies.yaml и выполните:
.venv/bin/python3 -m src.etl.run_pipeline --lake rossokhi --to-postgis
```
